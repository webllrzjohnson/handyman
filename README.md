# Handyman Price Guide

Local Toronto/Ontario handyman pricing advisor.

## Goal

Help Louie estimate fair client pricing for basic handyman jobs by selecting category, job, condition, urgency, and add ons.

## MVP features

- Local Next.js app.
- TypeScript pricing data, no database yet.
- Toronto/Ontario seed prices with source notes.
- Calculator with suggested quote, market range, time estimate, included scope, exclusions, and trade warnings.
- Client message generator.

## Run locally

```bash
npm run dev
```

Open the local URL shown by Next.js.

## Verify

```bash
npm run lint
npm run build
```

## Notes

Pricing is planning guidance, not a guaranteed quote. Licensed trade rules must be checked before offering work that touches electrical, plumbing alterations, gas, HVAC fuel equipment, fire/life safety, structural, elevators, or asbestos.
