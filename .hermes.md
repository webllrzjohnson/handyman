# Handyman Price Guide Rules

Local MVP for Louie's Toronto/Ontario handyman pricing advisor.

## Stack
- Next.js with TypeScript and Tailwind.
- No database until needed. Start with local TypeScript pricing data.
- Run locally first. Do not deploy unless Louie explicitly approves.

## Product rules
- Keep pricing transparent: base labour, materials, condition adjustments, urgency, and add ons.
- Show low, fair, and premium ranges where useful.
- Include licensed trade warnings for electrical, plumbing, HVAC, gas, fire/life safety, structural, elevators, and asbestos.
- Use trade status values: handyman OK, caution, licence required, and do not accept.
- For paid electrical work in Ontario, mark wiring, fixtures, switches, outlets, panels, and circuits as Licensed Electrical Contractor required unless Louie has verified a lawful exemption.
- For gas and fuel equipment, mark as TSSA certified technician required.
- Treat researched price sources as planning guidance, not guaranteed quotes.
- Prefer Toronto/Ontario data first.

## Verification
- Run `npm run lint` and `npm run build` before calling changes complete.
